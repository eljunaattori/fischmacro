---- Before running the script ----

ROBLOX settings: Disable shift-lock, enable fullscreen, set graphics quality to lowest, set reduce motion on.
In-game settings: Set extra brightness and saturation to 0%, disable environment tints, set VFX visibility to hide all, disable shadows and clouds

---- Known issues ----

-- Currently updated for v0.8 rev3 --

General tab

Auto camera mode and auto blur, can have issues with some misclicks.
Shake type key is not fully implemented yet
Rod skins haven't been implemented, only the Onirifalx has a partial color profile.

Advanced tab

Support for rods with custom UI where the control bar has a color gradient haven't been fully implemented yet.
